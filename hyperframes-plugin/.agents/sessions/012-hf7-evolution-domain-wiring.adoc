= Session 012 — HF-7 évolution : Pronunciation Domain Wiring
:date: 2026-07-09
:status: ✅ TERMINÉ — Câblage du PronunciationDomainLoader dans le pipeline Gradle

== Mission

Câbler le `PronunciationDomainLoader` (livré session 010) dans l'extension
Gradle et la task `generateHyperframesHtml`, avec merge automatique
auteur/domaine (author > domain > empty). Le pattern DDD/TDD/BDD baby-step
éprouvé sur HF-5 et HF-7 est appliqué : value object → processor → tests
unit (Red) → impl (Green) → Cucumber EN (critères acceptation).

== Constat de départ

`PronunciationDomainLoader` existait et était testé en isolation (session
010, HF-7d), mais n'était PAS câblé dans le pipeline. `HyperframesExtension`
n'avait pas de propriété `pronunciationDomain`, `GenerateHyperframesHtmlTask`
ne chargeait aucun dictionnaire de domaine, `HyperframesHtmlProcessor` ne
recevait pas de domaine. Le domaine pré-câblé `video-fr` était inerte.

- `HyperframesHtmlProcessor.kt` — refactor majeur :
  - Constructeur internal `(... domainDictionary: PronunciationDictionary?)` +

  - Méthode `withDomainDictionary(domain): HyperframesHtmlProcessor` (copie
    immuable, le receiver n'est pas muté).
  - `expandPronunciationBlocks` ne rend plus directement le JSON island — il
    collecte les hints auteur dans un `blockDictionary` partagé. L'injection
    finale se fait en une seule passe.

    auteur avec langue ne override que la langue correspondante. Domain-only
    words conservés. Domain jamais muté (filtered copy).

== Décisions techniques

. **Merge sémantique author-over-domain** : un hint auteur sans langue
  supprime tous les hints domaine du même mot (toutes langues). Justification :
  l'auteur qui écrit `narration: my-override` (sans langue) s'attend à override
  le domaine `narration: na-ra-syon` (langue fr). Sans cette règle, les clés
  `word|_` et `word|fr` ne dédupliquent pas → le hint domaine persiste.
. **Domain jamais muté** : `mergeAuthorOverDomain` travaille sur une copie
  filtrée du domaine. Test `domain dictionary is not mutated by the processor`
  verrouille cette propriété. Permet de réutiliser le même domaine pour
  plusieurs documents dans un même build.
. **Injection en une seule passe** : refactor de `expandPronunciationBlocks`
  (rendait directement) → collecte dans `blockDictionary`. L'island final est
  injecté par `injectPronunciationIsland` après que tous les hints auteur
  (block + inline) sont collectés. Évite les islands multiples et garantit
  l'ordre de precedence.
. **HyperframesWorld.createProject() idempotent** : `if (::projectDir.isInitialized
  && projectDir.exists()) return`. Permet au step `the project uses the
  pronunciation domain` de créer le projet avec le domaine configuré, puis aux
  steps existants (`source contains...`) d'être réutilisés sans écraser le
  build.gradle.kts.
