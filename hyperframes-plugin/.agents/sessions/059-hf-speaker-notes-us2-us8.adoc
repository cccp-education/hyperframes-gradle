== Livré (baby-step DDD/TDD/BDD strict)

* **US-2 — extraction.** Domaine pur `hyperframes.notes` (`SpeakerNote`,
  `SpeakerNotesDocument`, `SpeakerNotesExtractor`) : grammaire **N1 partagée**
  (`SpeakerNoteBlockParser`) + mapping note → **ordinal de scène** (sections de
  niveau 2, titre du document exclu, titres dupliqués résolus séquentiellement).
* **US-3 — injection.** `HyperframesHtmlProcessor.withSpeakerNotes(...)` : le
  bloc `admonitionblock note speaker` est **retiré** et remplacé, dans l'ordre du
  document, par un marqueur `hyperframes-track hyperframes-narration`
  **masqué** (`style="display:none"` — une note se dit, ne s'affiche pas),
  porteur de `data-narration-index/title` puis, au rendu, `data-narration-scene`
  et `data-narration-start`. Les hints `hf:pron[…]` d'une note empruntent le
  chemin des pistes (extraction + retrait). Zéro note = HTML **byte-identique**.
* **US-4 — TTS par scène.** `NarrationTrackExtractor.extractNarration` : si le
  document porte des notes, la narration **est** les notes (une prise par scène,
  ordre des scènes) ; sinon les pistes explicites historiques.
* **US-5 — muxage.** `NarrationMuxPlanner` (alignement prise ↔
  `data-narration-start`), `NarrationMuxCommand` (argv FFmpeg pur), tâche
  `muxHyperframesNarration` (opt-in, hors `hyperframesPipeline`) : `adelay` par
  scène, `amix` sans normalisation, `apad` + `-shortest` (la **vidéo borne**
  toujours), flux vidéo **copié** ; dégradé (fichier précédent conservé) et
  `strict` pour promouvoir en échec.
* **US-6 — traçabilité N3.** `HyperframesParseContext.speakerNotes`
  (`[{sceneId, title}]`) lu sur les ancres — champ additif, vide sans note.
* **US-7 — BDD + FT + dogfooding.** Feature `hf_speaker_notes.feature`
  (`@speaker-notes`, 5 scénarios : extraction/ordre, scène muette, hints, N3,
  filtre de mux) + steps préfixés (S-088) + `HyperframesNarrationMuxTest`
  (TestKit, FFmpeg **stub** : graphe, passthrough, dégradé, strict) +
  **dogfooding réel** `/tmp` (espeak + ffmpeg 6.1.1).
* **US-8 — docs.** `doc/PILOTAGE_HYPERFRAMES.adoc` (§ Notes d'orateur) +
  `README.adoc` (EN) + table des tâches.

== Découvertes (corrigées en session)

. **Le marqueur aurait affiché la note.** Corrigé : `display:none` inline.
. **`-shortest` tronquait la vidéo** (12,29 s au lieu de 15 s) quand la narration
  est plus courte que la vidéo. Corrigé : `apad` sur le mix → la vidéo borne.
. **La collecte des prises était un répertoire**, pas ses fichiers
  (`ConfigurableFileCollection.from(dir)` → zéro prise). Corrigé : `fileTree`
  filtré `*.wav`. Attrapé par le **dogfooding**, pas par les tests (leçon).

'''

== Dogfooding réel (`/tmp/opencode/hf-speaker-dogfood`)

Document 2 scènes (titre + 2 sections) → `generateHyperframesHtml`
(marqueurs ancrés à 5 s et 10 s, zéro admonition, note masquée) →
`generateHyperframesNarration` (2 prises espeak, 0 muette) →
`muxHyperframesNarration` sur un MP4 testsrc 15 s → **MP4 15,000 s, h264 + aac**,
`silencedetect` : silence 0→5, voix 5→7,5, silence 7,5→10, voix 10→12,
