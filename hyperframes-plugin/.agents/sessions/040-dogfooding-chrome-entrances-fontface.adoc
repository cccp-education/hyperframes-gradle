== Défauts révélés (corrigés)

. **`font_family_without_font_face`** — `hyperframes lint` rejette `Impact`
   (et toute famille nommée) sans déclaration `@font-face`, même avec un
   fallback générique. Correctif : `TypographyConfig.fontFaceCss()` émet un
   `@font-face{font-family:'X';src:local('X')}` par famille nommée, dédupliqué,
   génériques exclus (`sans-serif`, `monospace`, `system-ui`, …).
. **`text_below_floor`** — le timecode chrome (19 px) et le code inline (27 px)
   sous le plancher de 28 px. Correctif : topbar chrome `28 px`, `pre` `32 px`.
. Le warning `film_silent` reste **attendu** : le document de dogfooding n'a
   pas de piste audio (aucun bug).
