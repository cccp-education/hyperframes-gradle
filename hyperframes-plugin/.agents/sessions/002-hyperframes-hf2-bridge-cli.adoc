== Problèmes rencontrés et solutions

. *Interpolation Kotlin dans scripts shell* — `$var` dans les raw strings Kotlin était interprété. Solution : `${'$'}` pour les `$` bash littéraux.
. *Résolution Node.js complexe* — Pas d'accès direct à `NodeExtension` sans couplage fort. Solution : résolution par override + chemins connus + fallback PATH.
. *Extension → Task wiring* — Les `Property` de l'extension ne se propagent pas automatiquement. Solution : `finalizeValueOnRead()` + `set()` explicite dans le plugin.
. *Test timeout réel* — Le test timeout attend 5s réel (sleep bash). Solution : timeout court (500ms) pour exécution rapide.
