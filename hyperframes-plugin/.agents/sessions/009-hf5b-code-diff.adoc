== Décisions techniques

=== Coloration syntaxique lexicale maison

Pas de Prism.js / highlight.js (évite une dépendance CDN supplémentaire).
Fonction `highlight()` Kotlin pure qui wrap les mots-clés du langage dans des
`<span class="hf-kw">`. Évolutif via une future option `highlight="prism"`.
5 langues : kotlin, java, python, javascript/typescript.

=== Regex processor — capture explicite des 2 listings

Première tentative avec `(.*?)` non-greedy sur toute la sectionbody : le body
était tronqué (s'arrêtait au 2ème listingblock, avant son `</div>` fermant).
Deuxième tentative avec `(.*)` greedy : le body sur-consommait les `</div>` du
footer. Solution retenue : **capture explicite des 2 `listingblock` consécutifs**
dans la regex du bloc, avec `.*?` non-greedy sur chaque listing individuellement.
Robuste face aux `</div>` imbriqués et aux éléments annexes (footer, content div).

=== Lang extrait du data-lang, duration par défaut

AsciidoctorJ ne rend pas les attributs custom (`lang="kotlin"`, `duration=4`)
du bloc `[.hyperframes-code-diff#id]` comme attributs HTML du sect1. Seul `id`
est rendu dans `<h2 id="...">`. Le `lang` est extrait du `data-lang` du premier
`<code>`. `duration` reste à 3.0 par défaut — le parsing d'attribut custom
AsciiDoc sera une évolution future.
