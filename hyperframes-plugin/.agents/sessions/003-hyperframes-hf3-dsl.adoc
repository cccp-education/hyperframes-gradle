== Syntaxe DSL supportée

```asciidoc
= Titre
:hyperframes-width: 1920
:hyperframes-height: 1080
:hyperframes-fps: 30

[.hyperframes-composition#intro]
== Introduction

[.hyperframes-track]
Texte du track

[.hyperframes-animation]
----
const tl = gsap.timeline({ paused: true });
tl.from("#title", { opacity: 0, y: 40, duration: 0.8 }, 1);
----
```

→ Génère HTML avec stage div, data-composition-id, data-track-index/start/duration, scripts GSAP.

== Problèmes rencontrés et solutions

. *Syntaxe AsciiDoc pour role+id* — `[hyperframes-composition, id="intro"]` ne fonctionne pas avec AsciidoctorJ car le premier positional attribute est ignoré pour les sections. Solution : `[.hyperframes-composition#intro]` (shorthand AsciiDoc standard).
. *Indentation trimIndent()* — `trimIndent()` ne fonctionne pas quand des variables interpolées ont des indentations différentes. Solution : `buildString { appendLine() }` sans trimIndent.
. *Animation listingblock* — Le `[hyperframes-animation]` suivi de `----` produit `<div class="listingblock"><pre>code</pre></div>`, pas un `<p>`. Solution : regex adaptée pour capture `<pre>...</pre>`.
. *ID sur heading enfant* — AsciidoctorJ met l'id sur le `<h2>`, pas sur le `<div class="sect1">`. Solution : scan du premier heading enfant pour extraire l'id.
