== Livré

=== US-5 — FT TestKit du graphe complet

`HyperframesPipelineMusicFunctionalTest` (2 tests, herméticité totale : ni
Node, ni Chromium, ni ffmpeg — le CLI est un **stub** qui écrit un MP4 marqueur
depuis `--output`).

* **Ordre du graphe prouvé** sur la sortie du build :
  `generateHyperframesHtml` < `resolveHyperframesBgm` < `renderHyperframes`.
* **Data boundary** : la composition référence `data-track-id`/`src`, l'asset est
  copié à côté du HTML, le MP4 marqueur est produit.
* **Idempotence / Économie d'encre** : second passage (`--rerun-tasks`) —
  aucune recopie (`Music assets already in place`), `lastModified` préservé.

. **Le stub CLI reste la preuve du graphe** : le rendu réel est déjà couvert par
   le workflow `real-render-hyperframes.yml` (skip-gardé) ; le FT hermétique
