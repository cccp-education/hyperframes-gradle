== Mission

US-4 de l'EPIC `HF-MUSIC-LIBRARY` : lire le manifeste `music-library.json`
(producteur newpipe), **copier** les pistes référencées par la composition à
côté d'elle (`assets/audio/<track-id>.<ext>`, skip si `sha256` identique), et
exposer le DSL `hyperframes { music { … } }` (bibliothèque + ambiance de repli).

== Livré

=== Domaine pur

[cols="2,5", options="header"]
|===
| Élément | Rôle

| `MusicAssetPlanner` | La **composition HTML est le contrat** : `<audio class="hyperframes-music" data-track-id="…" src="…">` → requêtes → plan `copies`/`upToDate`/`missing`. Le système de fichiers est injecté (`existsSha256`), donc la règle de skip est testée sans disque.
| `MusicAssetCopy(trackId, src, source, sha256)` | une copie planifiée (source = racine audio + `file` du manifeste).
| `MusicModel.kt` | **copie N2 verbatim** du contrat `video.kernel.music` (`MusicLicence`, `MusicTrack`, `MusicLibrary`, `MusicSelection`, `MusicTrackSelector`) — voir « Décision de frontière ».
| `SoundResolution.Resolved.trackId` + `data-track-id` émis | le processeur transmet l'identifiant de piste à la tâche de copie (jamais de devinette sur le nom de fichier).
| `MusicDeclaration.fallback(...)` | ambiance de composition (DSL) partagée entre l'extension et la tâche HTML (pas de duplication de la règle).
|===

== Décision de frontière — pourquoi une copie N2 du contrat N1

`video.kernel.music` n'existe qu'en **0.8.0**, publié **uniquement sur JitPack**
(Central est bloqué à 0.7.0 tant que le canal Sonatype est restreint).

Un **plugin publié** ne peut pas dépendre d'un artefact absent des dépôts du
consommateur : la résolution échoue à la configuration (`Could not find
com.github.cccp-education:video-kernel-gradle:v0.8.0`) — reproduit sur les
scénarios TestKit *et* sur un consommateur réel. Le pont JitPack, tenté en début
de session, a donc été **retiré** (le POM est public, il doit rester résoluble).

Choix retenu (fallback D4 du cadrage) : `hyperframes.sound.MusicModel.kt` garde
une **copie verbatim** du contrat (licence fail-closed incluse), le noyau reste
épinglé à `0.7.0` (Central). **À ré-aligner** sur `video.kernel.music` dès que
`education.cccp:video-kernel:0.8.0` est sur Central (reset du canal, ≤ 2026-12-01) :
supprimer `MusicModel.kt`, ré-importer `video.kernel.music.*`, bumper le catalogue.

== Bugs réels révélés par le dogfooding (2)

. **Ordre de graphe** : `tasks.named("renderHyperframes")` était appelé avant
  l'enregistrement de la tâche → **application du plugin en échec** pour tout
  consommateur (« Task with name 'renderHyperframes' not found »).
. **Requête anticipée d'un provider absent** : `from(RegularFileProperty)` réalise
  la valeur à la configuration → tous les consommateurs **sans** `music { }`
  échouaient (« Cannot query the value of property 'libraryFile' »). Corrigé par
  `.map { listOf(it) }.orElse(emptyList())`.

Les deux ont été reproduits hors suite de tests (consommateur `/tmp` via
`includeBuild`, chemin identique à TestKit), corrigés, puis prouvés par la CI.
