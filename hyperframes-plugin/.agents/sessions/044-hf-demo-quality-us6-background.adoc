== Mission

Poursuivre la **qualité vidéo** du borough (priorité actée S-036→S-043), sans
rouvrir le déploiement YouTube (gelé, décision pilote S-037). Dernier écart
identifié entre la démo de référence (`demo-video/`) et le DSL : le **fond média
plein cadre par scène** (image + scrim de lisibilité + grille + grain).

Cadrage : `.agents/CADRAGE_EPIC_HF_DEMO_QUALITY_US6.adoc`.

== Décisions

. Périmètre **image uniquement** : les fonds `<video>` restent hors scope (le
  runtime possède le cycle de vie des médias temporels).
. DSL par bloc de liste `[.hyperframes-background]` (patron
  `[.hyperframes-audio]`), consommé par la scène (jamais rendu en contenu).
. Clés tolérantes : `file` (obligatoire), `opacity` (0..1, défaut `0.55`),
  `scrim` (`true`), `grid` (`false`), `grain` (`false`). Bloc invalide = fond
  ignoré, jamais d'échec de build.
. Domaine pur `hyperframes.media` : `BackgroundImage` (invariants),
  `BackgroundImageParser` (liste → modèle), `BackgroundImageHtml` (modèle →
  fragment) — zéro I/O, zéro Gradle.
. **Backward compatible** : le CSS de fond est émis **uniquement** si au moins
  une scène déclare un fond ; sans bloc, la composition reste byte-compatible
  (`.scene-bg` historique, aucun token `hf-bg`).
. **Aucune** modification de `ReferencedAssets` : le `<img>` synthétisé est déjà
  couvert par le scan `<img src>` (US-3) — l'asset est copié à côté de la
  composition.

== Fait

=== Domaine `hyperframes.media`

* `BackgroundImage` — modèle immuable, invariants (`file` non blanc,
  `opacity ∈ [0,1]`), défauts documentés.
* `BackgroundImageParser` — `key: value` par ligne, commentaires `#`, clés
  inconnues ignorées, opacité invalide/hors bornes → défaut, fichier absent →
  `null`.
* `BackgroundImageHtml` — fragment `hf-bg` (image `alt=""`,
  `aria-hidden="true"`, `style="opacity:…"`) + overlays `hf-bg-scrim` /
  `hf-bg-grid` / `hf-bg-grain`, échappement attribut.

=== Processeur

* Extraction du bloc par scène (retiré du contenu), parsing, portage du modèle
  dans `RawScene`/`Scene`.
* `renderSceneBackground` : `.scene-bg` historique, ou couche média si déclarée.
* `BACKGROUND_CSS` conditionnel (opt-in strict).
