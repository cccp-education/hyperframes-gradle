== Décisions techniques

=== Syntaxe DSL AsciiDoc — role avec point

`[.hyperframes-pronunciation]` (role avec point) produit
`<div class="listingblock hyperframes-pronunciation">`. Sans le point,
AsciidoctorJ ignore le style et la classe n'est pas appliquée. Même
constat pour les tracks : `[.hyperframes-track]` au lieu de
`[hyperframes-track, ...]`.

=== Syntaxe inline hint — macro custom `hf:pron[]`

Première tentative `<<dos|do>>` : interprété par AsciidoctorJ comme xref
(cross-reference), pas comme texte brut. Deuxième tentative `hf:pron[dos, do]`
(macro inline non reconnue) : AsciidoctorJ la laisse telle quelle dans le HTML,
le processor peut l'extraire. Le mot reste visible, la phonétique est consommée
par le TTS via le dictionnaire JSON.

=== Factory `of()` pour normalisation

`PronunciationHint` est une data class avec constructeur privé + factory
`of()` qui normalise (word trim+lowercase, phonetic trim) et valide
(non-empty). Permet `copy()` cohérent et égalité basée sur les valeurs
normalisées.

=== `find()` avec fallback language

Le dictionnaire stocke les hints par clé `word|language` (ou `word|_` sans
langue). `find(word, language)` privilégie le match exact de langue, puis
retombe sur le hint sans langue, puis sur n'importe quel hint du mot. Permet
aux dictionnaires de domaine (qui ont `language` setté) d'être trouvés même
sans préciser la langue.

=== Contrat N3 étendu — pronunciation optionnel

`HyperframesParseContext.pronunciation` est `null` par défaut (backward
compat). Quand l'îlot JSON est présent dans le HTML, `parsePronunciation`
extrait les entries (word, phonetic, language) et le count.
