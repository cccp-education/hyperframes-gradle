== Contexte

`HF-DEMO-QUALITY US-2` (S-036) avait livré les transitions **cover**
(`grid`/`shutter`/`fade`) : les deux scènes ne se chevauchent pas, un overlay
possède le handoff. `US-2b` ajoute les transitions **à chevauchement** :
`blur-crossfade` et `vertical-push`, où la scène entrante démarre **avant** la
fin de la sortante et les deux clips restent visibles sur leurs pistes.

Décision pilote S-037 : **arrêter le déploiement YouTube** et concentrer les
sessions sur la **qualité de génération vidéo** (hyperframes / capsule /
video-kernel).

'''
== Livré

* `TransitionKind` + `BLUR_CROSSFADE` / `VERTICAL_PUSH` ; `Transition` porte une
  fenêtre de chevauchement de **0,6 s**.
* Calcul des scènes en deux passes (`RawScene` → `Scene`) : la scène suivante
  démarre à `start + duration - overlap` ; la durée totale diminue d'autant.
  Dernière scène : rôle ignoré (pas de chevauchement sans cible).
* `rootTl` pilote les deux wrappers pendant la fenêtre partagée :
  ** `blur-crossfade` : sortante `opacity 0` + `filter blur(18px)`, entrante
     `opacity 1` + `blur(0)` ;
  ** `vertical-push` : sortante `yPercent -100`, entrante `yPercent 100 → 0`.
* Aucun overlay cover pour ces deux rôles ; les transitions cover existantes
  sont inchangées (rétro-compatibilité).
* Les scènes impliquées dans un chevauchement portent
  `data-layout-allow-overlap` + `data-layout-allow-overflow` sur leur
  `.scene-inner` : le chevauchement est **intentionnel**, pas un défaut de layout
  (le marqueur sur la racine de scène est ignoré par le check HyperFrames).
* Documentation `doc/PILOTAGE_HYPERFRAMES.adoc` mise à jour (rôles, chevauchement,
  marqueurs).

== Pièges

1. *(S-037)* Une transition à chevauchement doit décaler le `data-start` de la
   scène entrante ; un overlay sans chevauchement ne montre qu'une scène.
2. *(S-037)* Le check de layout signale le chevauchement de texte et le débordement
   canvas comme des défauts ; marquer le **conteneur interne** de la scène
   (`data-layout-allow-overlap`/`-overflow`), jamais la racine de scène.
3. *(S-037)* La scène sortante ne doit pas faire son fondu historique : le
   `rootTl` possède le handoff.
4. *(S-037)* Ne pas republier `0.0.9` en local : le code a changé, la prochaine
   release est `0.0.10`.
