== Prérequis CI (BS-0) — la CI était rouge sur 100 % des runs

Constat en ouverture (`gh run list`) : **tous les runs sont `failure`**, y compris
celui qui portait le fix S-016. Deux causes structurelles :

. **Configuration** — `settings.gradle.kts` exigeait `ossrhUsername`/`ossrhPassword`
   (`?: error(...)`), reverté au commit `dacf6c3` « out-of-scope ». Sur un runner
   sans `~/.gradle/gradle.properties`, la configuration échoue (~40 s).
   → tolérance `?: ""` restaurée (miroir exact de `capsule-plugin/settings.gradle.kts`).
. **Gardes de publication racy** — `HyperframesPluginPublicationTest` lisait le
   *working tree* du repo voisin `../workspace-bom/gradle/libs.versions.toml`,
   **absent du runner isolé** et racy entre sessions parallèles (échec prouvé :
   `java.lang.IllegalStateException at HyperframesPluginPublicationTest.kt:66`,
   `185 tests completed, 2 failed`). → patron **D5-RACE** (graphify S-029) :
   les versions du catalogue **publié** sont *injectées par Gradle*
   (`systemProperty("hyperframes.publishedCatalog.pluginVersion", ws.versions.hyperframes.plugin.get())`
   et `...bomVersion`, depuis `ws.versions.workspace.bom`). La garde ne lit plus
   jamais un repo voisin ; RED-prouvable par propriété absente.
