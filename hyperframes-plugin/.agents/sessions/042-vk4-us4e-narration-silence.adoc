== Mission

Devenir le **second consommateur** réel des primitives audio partagées promues
au noyau `video-kernel 0.6.0` (`RmsEnvelope`, `AudioSilenceDetector`,
`SilenceAnalysis`) et brancher la détection sur les narrations HyperFrames.

== Constat

`generateHyperframesNarration` synthétise `narration-<n>.wav` mais **ne vérifie
pas** que le take porte du signal. Un TTS NoOp/cassé produisait un WAV
techniquement valide mais muet, invisible avant le rendu final.

== Design

* **Noyau N1** : `AudioSilenceDetector` (décision pure, indépendante de l'ASR).
* **Adapter N2** : `hyperframes.post.AudioEnvelopeProbe` (ffmpeg → PCM s16le →
  `RmsEnvelope`), `-y` obligatoire (le fichier temporaire existe déjà).
* **Décision de fichiers** : `hyperframes.post.NarrationSilenceCheck` (pure,
  sonde injectée ; une sonde absente n'est jamais lue comme « propre »).
* **Wiring** : `GenerateHyperframesNarrationTask` journalise
  `narration is silent` par take muet ; jamais fatal (la tâche est opt-in et
  la sonde est optionnelle).
* **Pins** : `workspace-catalog/BOM 0.0.112`, `video-kernel 0.6.0`.
