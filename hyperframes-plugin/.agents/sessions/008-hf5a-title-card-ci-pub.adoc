== Difficultés rencontrées

1. **Subtitle non extrait** — la regex `paragraphRegex` initiale `<div class="paragraph"><p>(.*?)</p></div>` ne matchait pas car AsciidoctorJ produit des newlines entre balises. Corrigé avec `\s*` : `<div class="paragraph">\s*<p>(.*?)</p>\s*</div>`.
2. **Test "without subtitle" faux négatif** — la timeline GSAP référenait `hf-title-card-subtitle` même quand subtitle absent. Corrigé : les lignes GSAP sont conditionnelles (logo, subtitle n'émis que si présents).
3. **Isolation scénarios Cucumber** — le `buildDir` persistait entre scénarios, causant UP-TO-DATE. Corrigé : `writeTitleCardAdoc` supprime `buildDir` + `srcDir`, `runTask` utilise `--rerun-tasks`.
4. **Task `clean` inexistante** — le plugin `base` n'est pas appliqué dans le project de test. Corrigé : `--rerun-tasks` au lieu de `clean`.

== Décisions techniques

* **Template = value object pur** — `TitleCardTemplate` est un `data class` sans effet de bord, `render()` est une pure function. Testable isolément, aligné DDD.
* **Expansion avant composition** — `expandTitleCardBlocks` est appelée AVANT `enhanceCompositionBlocks` dans le pipeline `enhance()`. Le template génère déjà `data-composition-id`, évitant la duplication.
* **Timeline GSAP conditionnelle** — les `tl.from()` ne référencent que les éléments réellement présents. Évite les sélecteurs CSS vides.
* **Gherkin EN** — feature et steps en anglais (règle AGENTS.adoc : Gherkin EN, pas de `# language: fr`).
