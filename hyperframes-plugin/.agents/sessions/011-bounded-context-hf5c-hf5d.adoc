=== HF-5c — Template "data-chart" (graphique animé)

- `DataChartTemplate` value object DDD (id, title, dataPoints, durationSeconds=4.0).
- `DataPoint` value object imbriqué (label non-blank, value non-negative).
- `render()` produit un fragment HTML HyperFrames : composition + track +
  conteneur `hf-data-chart` + titre + un div `hf-data-chart-bar` par point
  (hauteur proportionnelle à value/maxValue%), label visible, timeline GSAP
  `scaleY: 0` → `scaleY: 1` avec `stagger: 0.15` (bars montent l'une après
  l'autre).
- `expandDataChartBlocks` processor : détecte `[.hyperframes-data-chart#id]`
  AsciiDoc + listingblock `label: value` → remplace par le rendu. Regex
  tolérant (lignes mal formées silencieusement ignorées).
- Tests : 13 unit (Red → Green) + 4 Cucumber EN (data_chart_template.feature).
- Helper `HyperframesWorld.writeDataChartAdoc` ajouté.
- Bug fix : conteneur renommé `hf-data-chart-bars` → `hf-data-chart-plot`
  (collision substring avec `hf-data-chart-bar` dans le test empty chart).

=== HF-5d — Template "kinetic-captions" (sous-titres animés synchronisés)

- `KineticCaptionsTemplate` value object DDD (id, captions, durationSeconds=5.0).
- `Caption` value object imbriqué (start non-negative, end >= start, text non-blank).
- `render()` produit un fragment HTML HyperFrames : composition + track +
  conteneur `hf-kinetic-captions` + un div `hf-kinetic-caption` par caption
  (hidden par défaut via `display:none`, `data-start`/`data-end`), timeline
  GSAP `opacity: 0 → 1` à start, `opacity: 1 → 0` à end.
- `expandKineticCaptionsBlocks` processor : détecte
  `[.hyperframes-kinetic-captions#id]` AsciiDoc + listingblock
  `start -> end: text` → remplace par le rendu.
- Tests : 14 unit (Red → Green) + 4 Cucumber EN (kinetic_captions_template.feature).
- Helper `HyperframesWorld.writeKineticCaptionsAdoc` ajouté.
- Bug fix : AsciidoctorJ échappe `->` en `-&gt;` dans les `<pre>` — le regex
  du processor a été élargi pour accepter `-&gt;`, `&#8594;` et `->`.
