== Contexte

`HF-MUSIC-LIBRARY` était le dernier EPIC métier ouvert de hyperframes hors
`HF-SPEAKER-NOTES` (bloqué par la publication de `video-kernel 0.9.0`). L'US-8
demandait le **chevauchement temporel** de deux cues entre scènes — le planificateur
existait (US-3) avec seulement des fondus de passation **dos à dos**.

Décision : chevauchement **opt-in** (`crossfade:`), défaut `0`, pour ne changer
aucun document existant (rétro-compatibilité stricte).

'''

== Livré

* `MusicDeclaration.crossfadeSeconds` (`>= 0`, défaut `0`) — déclaré sur la cue
  **entrante** ; `sameMusicAs` reste une identité (une continuité ne redémarre
  jamais la piste, donc n'ouvre pas de crossfade).
* `SoundSequencePlanner` :
  - à l'ouverture d'une nouvelle cue, si `crossfade > 0`, la cue sortante est
    **étendue** de `min(crossfade, fin de composition − frontière)` ;
  - `fade-out` sortant / `fade-in` entrant prennent le chevauchement par défaut ;
    un fondu **explicite** est préservé ;
  - un `stop` et une continuité n'appliquent **jamais** le crossfade ;
  - garde de durée totale (le chevauchement ne dépasse pas la composition).
* `SoundBlockParser` : clé `crossfade:` (blocs `----` et open blocks `--` aplatis).
* `doc/MUSIQUE_ET_SON.adoc` : clé + sémantique + limites (courbes linéaires).

'''
