= SESSION_PROCEDURE — hyperframes-gradle

== Procédure de Fin de Session — 6 Étapes Obligatoires

. *Rapport de session* — Créer `.agents/sessions/NNN-sujet.adoc`
. *Mise à jour PROMPT_REPRISE.adoc* — Contexte de reprise session N+1 (max 70 lignes)
. *Mise à jour INDEX.adoc* — Numéro de session, roadmap, statut EPICs
. *Mise à jour SESSIONS_HISTORY.adoc* — Ajouter l'entrée dans l'historique
. *Archivage COMPLETED_TASKS_ARCHIVE.adoc* — Archiver les tâches terminées
. *Vérification* — `git status`, absence de secrets, build compile

== Commandes de Vérification

[source,shell]
----
# Vérifier l'état git
git status

# Vérifier l'absence de secrets
grep -r "TOKEN\|SECRET\|PASSWORD\|API_KEY\|gho_\|ghp_" --include="*.kts" --include="*.properties" --include="*.yml"

# Vérifier que le build compile
./gradlew :hyperframes:compileKotlin

# Vérifier que les tests passent (NE PAS LANCER sans permission)
# ./gradlew check
----

== Rappels

* HyperFrames CLI = plugin Gradle Node (`com.github.node-gradle`) gère Node.js + package npm hyperframes (pinné, download auto)
* AsciidoctorJ en implementation (HF-1) → passera en compileOnly en HF-4 (partagé avec codex-gradle)
* Contrat par fichiers : AsciiDoc → HTML HyperFrames → MP4
* Bridge Node.js : `node hyperframes-cli render` via ProcessBuilder + plugin Gradle Node, pas de npx système
* Aucun commit sans permission explicite
