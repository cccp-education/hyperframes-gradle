=== 3.2 Storyboard — Pipeline de bout en bout

. **Rédaction** : Le formateur écrit son SPG en AsciiDoc (planner-gradle)
. **Annotation** : Il ajoute des blocs `[hyperframes-composition]` et
  des attributs docinfo `:hyperframes-width: 1920`
. **Génération HTML** : `./gradlew generateHyperframesHtml` parse
  l'AsciiDoc, extrait les blocs, génère le HTML avec data-* attributes
. **Rendu MP4** : `./gradlew renderHyperframes` appelle
  `node hyperframes-cli render` via ProcessBuilder + plugin Gradle Node
. **Production** : Puppeteer capture les frames, FFmpeg encode en
  h264+AAC, le MP4 est écrit sur disque
. **Indexation** : `collectHyperframesRetrieve` produit `metadata.json`
  (durée, dimensions, codec, date)
. **Assemblage** : runner-gradle ingère le JSON dans
  `assembleCompositeContext`
. **Déploiement** : Le MP4 + metadata sont déployés sur le site statique

=== 7.2 Décisions techniques

[cols="2,5,3", options="header"]
|===
| Décision | Justification | Alternative écartée
| AsciidoctorJ en implementation (HF-1)
| Nécessaire pour GradleTestKit ; passera en compileOnly en HF-4
| compileOnly (cassait les tests)
| ProcessBuilder pour bridge JVM ↔ Node.js
| Zéro couplage, isolation, upgrade indépendant
| J2V8, GraalJS (trop lourds)
| SafeMode.UNSAFE pour AsciidoctorJ
| Permet d'écrire dans /tmp avec TestKit
| SafeMode.SAFE (bloquait TestKit)
| Attributes.builder() pour passer les options
| API AsciidoctorJ 3.0.0 — constructeur package-private
| Attributes() (impossible), Map (non accepté)
| MP4 h264 + AAC
| Standard universel, compatible tous navigateurs
| WebM (Playwright natif, moins compatible)
|===

=== 7.3 Intégration reveal.js (slider-gradle)

HyperFrames est **complémentaire** à slider-gradle, pas concurrent :

[cols="2,3,3,3", options="header"]
|===
| Aspect | slider-gradle | capsule-gradle | **hyperframes-gradle**
| Entrée | AsciiDoc | reveal.js HTML | *AsciiDoc*
| Sortie | reveal.js HTML | WebM | *MP4*
| Use case | Slides formateur | Capsule révision | *Vidéo standalone*
| Pipeline | Asciidoctor Gradle | Playwright Java | *AsciidoctorJ + CLI Node.js*
| Temps réel | Non (build) | Oui (capture) | *Non (build)*
| Animation | reveal.js transitions | Capture écran | *GSAP data-attrs*
|===

La synergie :
- Un même AsciiDoc peut produire **slides** (slider), **PDF** (codex),
  **capsule vidéo** (capsule) et **vidéo standalone** (hyperframes)
- Les templates de slider et hyperframes partagent les conventions
  AsciiDoc (attributs docinfo, blocs customs)
- Le pipeline N3 orchestre les 4 flux en parallèle

=== 7.4 Risques et atténuations

[cols="1,3,3", options="header"]
|===
| Risque | Impact | Atténuation
| HyperFrames CLI API instable (v0.6.x)
| Cassure du pipeline rendu
| Pin de version, tests golden file MP4, alertes GitHub sur release
| Download Node.js échoue sur CI (proxy/réseau)
| Blocage du rendu
| Docker image avec Node.js préinstallé, skip conditionnel
| Headless Chrome lent (> 5 min)
| Timeout CI
| Timeout configurable (defaut 300s), cache des frames
| Conflit de version AsciidoctorJ avec codex-gradle
| Erreur de compilation runtime

=== B. Glossaire

|===
| Terme | Définition
| AsciidoctorJ | API Java pour parser et convertir des documents AsciiDoc
| Composition | Unité narrative d'une vidéo (intro, contenu, conclusion)
| Track | Calque média/timing dans une composition (vidéo, audio, texte)
| GSAP | GreenSock Animation Platform — animations JS seekable
| HyperFrames | Moteur open-source HTML → MP4 (HeyGen, Apache 2.0)
| ProcessBuilder | API Java pour lancer des processus externes (CLI)
