= hyperframes-gradle

Turn an annotated AsciiDoc document into a deterministic MP4 through the
https://github.com/heygen-com/hyperframes[HyperFrames] engine (Apache 2.0).

`education.cccp.hyperframes` is the N2 Gradle plugin of the *Watts* borough: the
document is the source of truth for **visuals, narration and sound** — no manual
post-production.

'''
== Requirements

* JDK 25 (Gradle toolchain).
* Node.js + the HyperFrames CLI (`npm install hyperframes`).
* `ffmpeg` / `ffprobe` for the optional post-production and duration probe.

'''
== Quick start

[source,kotlin]
----
plugins {
    id("education.cccp.hyperframes") version "<version>"
}

hyperframes {
    inputDir.set(layout.projectDirectory.dir("src/docs"))
    outputDir.set(layout.buildDirectory.dir("hyperframes"))
    width.set(1920)
    height.set(1080)
    outputName.set("capsule")
}
----

'''
== Tasks

[cols="2,4", options="header"]
|===
| Task | What it does

| `generateHyperframesHtml` | AsciiDoc → AsciiDoc HTML → conformant HyperFrames composition (`#stage`, one scene clip per section, vendored GSAP, embedded design system).
| `resolveHyperframesBgm` | Copies the music-library tracks referenced by the composition next to it (`assets/audio/`), skipping identical content (`sha256`).
| `renderHyperframes` | Renders the composition to MP4 through the shared `video.kernel.VideoEngine` port (delegates to the HyperFrames CLI).
| `generateHyperframesNarration` | Scene narration through the shared `video.kernel.TextToSpeech` port.
| `muxHyperframesNarration` | Opt-in mux of the speaker-note takes over the rendered MP4, aligned on the scene timeline. |
| `postProcessHyperframes` | Subtitle burn-in + audio post-production (loudness, BGM, ducking) through the shared N1 ports.
| `collectHyperframesRetrieve` | Exports the N3 `composite-context.json` contract for the runner.
| `publishHyperframesToYouTube` | Opt-in OAuth 2.0 upload (`videos.insert` resumable + `thumbnails.set`).
| `hyperframesPipeline` | The whole chain: HTML → sound assets → MP4.
|===

'''
== Sound: a sequence written in the document

Music is not a hidden setting. A scene declares its ambience, and the sequence
follows the document order (inheritance, explicit stop, hand-off fades):

[source,asciidoc]
====
[.hyperframes-music]
--
mood: documentary
volume: 0.25
fade-in: 1.5
--

[.hyperframes-sfx]
----
file: assets/audio/whoosh.mp3
offset: 0.8
----
====

The tracks come from a **versioned manifest** (`music-library.json`) produced by
the `newpipe` borough; the audio itself stays gitignored. The library is
fail-closed on licences (`own`, `cc0`, `cc-by`, `royalty-free`, `licensed`).

[source,kotlin]
----
hyperframes {
    music {
        libraryFile.set(layout.projectDirectory.file("music-library.json"))
        audioDir.set(layout.projectDirectory.dir("audio")) // default: manifest dir
        mood.set("calm")   // fallback bed, only when the document declares none
        strict.set(true)   // a missing asset fails the build
    }
}
----

* an unresolvable cue (unknown track, refused licence, missing library) fails
  **before** the render with an actionable message — never a silent
  video;
* a composition without sound blocks keeps its historical output byte-identical;
* the legacy `[.hyperframes-audio]` local BGM block still works and wins.

Full guide (French): `doc/MUSIQUE_ET_SON.adoc`.

'''
== Speaker notes: the video speaks

The document carries the **words** as well as the visuals. A speaker note is
authored under the scene it belongs to and becomes that scene's narration:

[source,asciidoc]
----
[.hyperframes-composition#intro]
== The document becomes signal

The visible content of the scene.

[NOTE.speaker]
--
Here we explain that the document is the source of truth.
The keyword hf:pron[signal, si-gnal] is spoken correctly.
--
----

* the note is **removed from the visual render** — it is never displayed;
* it becomes the **narration of its scene** (one take per scene, in scene order);
* the grammar is the shared N1 contract `video.kernel.notes` (same syntax as
  capsule, `video-kernel 0.9.x`);
* `hf:pron[…]` hints inside a note follow the same path as track hints;
* a scene without a note stays silent, and a document without notes keeps a
  **byte-identical** render.

[source,shell]
----
./gradlew generateHyperframesNarration muxHyperframesNarration
----

The mux is **opt-in** (not part of `hyperframesPipeline`): each take is delayed
to its scene start (`adelay`), all takes are mixed (`amix`), the video stream is
copied and `-shortest` bounds the audio on the video. No note, no take or no
rendered MP4 carries the previous file through with a warning; `strict = true`
turns those conditions into a failure. `metadata.json` exposes
`speakerNotes: [{sceneId, title}]` for the augmented context.
